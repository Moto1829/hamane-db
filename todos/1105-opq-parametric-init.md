# 1105: OPQ のパラメトリック初期値 (PCA + 固有値割り当て)

## ゴール

交互最適化の初期値に「パラメトリック OPQ」(共分散の固有分解 → 固有値割り当て)
を加える。乱数初期値より良い出発点を与え、候補比較の当たり率を上げる。

## やること

- [x] `hamane-core/opq.rs`: 対称行列の固有分解 (Jacobi 法、決定的)
- [x] 共分散行列 (学習サンプル、平均引き) の固有ベクトル V と固有値 λ
- [x] 固有値割り当て: λ 降順に、積が最小のサブベクトルへ貪欲に配る
      (各サブベクトルの固有値の積 = 分散の幾何平均を均す)
- [x] `R_param` = 割り当て順に並べた固有ベクトル行列 (直交)
- [x] `train` の候補に加える (恒等 / パラメトリック / 乱数 / 回転なし)

## 完了条件

- [x] Jacobi が既知行列の固有値を正しく返し、V が直交
- [x] 軸に沿った分散偏りデータでパラメトリック初期値が乱数初期値以上
- [x] 既存テスト green (「素の PQ より悪くならない」保証は維持)
- [x] SIFT (--rotate-input) の recall がパラメトリック追加前以上

## 実装メモ

- 固有分解は循環 Jacobi 法 (対称行列専用、決定的、外部クレート不要)。
  極分解の Newton 反復と同じく「専用アルゴリズムなら SVD は要らない」方針
- 固有値割り当ては「λ 降順に、その時点で λ の積が最小のサブベクトルへ入れる」
  貪欲法。PQ の歪みは各サブベクトルの分散の幾何平均の和で近似でき、積が回転で
  不変なので AM-GM より均等化が最小化になる
- **実測 (SIFT 200k)**: recall は乱数初期値版と同じ (回転入力 ef=64 で 0.9697
  vs 0.9699、素の SIFT で 0.9831 vs 0.9832)。**構築は 110.7s → 106.3s と約 5%
  短縮**。今回のデータでは恒等初期値の候補が勝つため差が出にくいが、
  乱数 seed への依存が消え、説明可能な出発点になった
- 乱数直交行列は学習からは外れたが、ベンチの `--rotate-input`
  (`OpqRotation::random_for_bench`) で引き続き使う
